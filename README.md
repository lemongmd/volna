<h1 align="center">Волна</h1>

<p align="center">Слушай музыку вместе с друзьями — одну и ту же, в одну и ту же секунду.<br/>
Бесплатно, без подписок и без «запиканных» треков.</p>

---

## Что умеет

- **Комнаты.** Создаёшь комнату → отправляешь другу 6-значный код → вы слышите один трек синхронно (точность ~0.1 с).
  Очередь, перемотка, пауза и «дальше» общие для всех.
- **Чат и реакции** 🔥💜😂 прямо в комнате.
- **Режим «управляет только хост»**: остальные могут только добавлять треки в конец очереди.
- **Хост ушёл — музыка не остановилась**: хостом автоматически становится следующий участник.
- **Поиск по YouTube Music, YouTube и SoundCloud.** Значок `E` — explicit-версия (без цензуры).
- **Любые ссылки**: YouTube, SoundCloud, плейлисты, альбомы и ещё 1000+ сайтов (всё, что умеет yt-dlp).
- **Ссылки Spotify** (трек, альбом, плейлист): Волна берёт названия и находит эти треки на YouTube.
- Медиаклавиши и плашка управления музыкой Windows.
- Дизайн: минималистичная тёмная тема, полупрозрачные панели, фон окрашивается под обложку текущего трека.

## Почему без цензуры

С 1 марта 2026 в российских стримингах (Яндекс Музыка, VK, Звук) в треках «запикивают» упоминания наркотиков.
Волна не использует эти сервисы: звук берётся с **YouTube / YouTube Music и SoundCloud**, где обычно лежат оригинальные
версии. Если на YouTube Music попалась «чистая» версия — переключи источник на YouTube или SoundCloud,
там почти всегда есть оригинал (часто залитый до 2026 года).

## Установка (Windows 10/11)

1. Открой вкладку **Actions** этого репозитория → последний успешный запуск «Сборка для Windows».
2. Внизу, в **Artifacts**, скачай `Volna-Setup-Windows` (установщик) или `Volna-Portable-Windows` (один .exe без установки).
3. При первом запуске Волна спросит имя и один раз скачает движок (~60 МБ: yt-dlp и Deno).

> Если сделать тег `v0.1.0` и запушить его — установщик автоматически появится во вкладке **Releases**.

### YouTube тормозит / не открывается

В РФ YouTube замедлен. Варианты:

- в **Настройки → Прокси** укажи свой прокси (`socks5://127.0.0.1:1080`, `http://127.0.0.1:2080` и т.п.) —
  через него пойдут поиск, загрузка и звук;
- или включи VPN / программы обхода замедления;
- или слушай с **SoundCloud** — он работает без этого.

Комнаты (синхронизация, чат) работают и без прокси.

## Как это устроено

**Стек:** [Tauri 2](https://tauri.app) (Rust) + [Svelte 5](https://svelte.dev). Вместо встроенного Chromium, как в
Electron, используется системный WebView2, поэтому приложение весит несколько мегабайт и ест в разы меньше памяти и процессора.

```
┌───────────── Волна (у каждого участника) ─────────────┐
│  Svelte UI ── <audio> ◄── stream://  (Rust-прокси)    │
│      │                         ▲                      │
│      │ команды/состояние       │ yt-dlp → прямая      │
│      ▼                         │ ссылка на аудио      │
│  MQTT по WebSocket             YouTube / SoundCloud   │
└──────┬────────────────────────────────────────────────┘
       ▼
 публичный MQTT-брокер (topic volna/v2/<КОД>/…)
```

- **Поиск** (`src-tauri/src/search.rs`): YouTube Music и YouTube — через внутренний API InnerTube, SoundCloud — через
  api-v2. Если быстрый путь сломался, запасной — через yt-dlp.
- **Звук** (`ytdlp.rs`, `stream.rs`): yt-dlp достаёт прямую ссылку на аудиопоток, а Rust отдаёт его в `<audio>` через
  свой протокол `stream://` кусками (HTTP Range) с нужными заголовками. Протухшие ссылки обновляются автоматически.
  HLS-потоки (часть SoundCloud) скачиваются в кэш целиком — это 3–8 МБ.
- **Комнаты** (`src/lib/sync.ts`): свой сервер не нужен — используются бесплатные публичные MQTT-брокеры
  (EMQX, HiveMQ, Mosquitto; если один недоступен, берётся следующий).
  - Хост — источник правды: хранит очередь и «якорь» времени («в момент T по моим часам трек был на позиции P»).
    Состояние публикуется retained-сообщением, поэтому новый участник сразу получает актуальную картину.
  - Участники шлют хосту команды, хост применяет их и рассылает новое состояние.
  - Часы сверяются с хостом по принципу NTP, так что неправильно выставленное время на ПК не мешает.
  - Мелкий рассинхрон плеер выравнивает незаметным изменением скорости (±5%), крупный — перемоткой.
- **Плеер** (`src/lib/player.ts`): один `<audio>`, следует общему состоянию. Следующий трек подгружается заранее.

### Свой сервер комнат

Публичные брокеры бесплатные, но общие: кто знает код комнаты, тот может в неё зайти. Если хочешь приватности —
подними свой MQTT-брокер с WebSocket (например, [Mosquitto](https://mosquitto.org) или
[EMQX](https://www.emqx.io)) и укажи его адрес в **Настройки → Сервер комнат** (`wss://твой-сервер:8084/mqtt`).
Адрес должен быть одинаковым у всех в комнате.

## Ограничения

- Сам Spotify отдаёт звук только с DRM, поэтому из Spotify берутся только названия, а музыка — с YouTube.
- Каждый участник загружает звук сам, со своего интернета (у всех должен открываться выбранный источник).
- YouTube регулярно меняет защиту. Если перестало играть — **Настройки → Движок → Обновить**.

## Структура

```
src/                    интерфейс (Svelte 5)
  lib/sync.ts           комнаты, команды, синхронизация часов
  lib/player.ts         плеер и выравнивание рассинхрона
  lib/state.svelte.ts   общее состояние
  components/           экраны и элементы
src-tauri/src/          Rust
  search.rs             поиск (YouTube Music, YouTube, SoundCloud)
  ytdlp.rs              потоки через yt-dlp, ссылки, Spotify
  stream.rs             протокол stream:// для <audio>
  deps.rs               установка и обновление движка
```
